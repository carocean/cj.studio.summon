# 可替换模型接入：当前可做与上线门槛

## 目标与当前决定

系统目标是生物理解用户当下需求，按需组织服务和呈现，不是把有限口令当最终产品，也不训练基础模型。当前运行主链继续使用诚实标注的有限规则；本轮本地小模型评测不合格，不无限换模型或把可运行等同可采用。

独立 `research/local-planner` 的协议探针仅帮助验证以后更换模型时的传输及输出边界，不向真实供应商发送数据，也不能证明任何模型语义可靠。它不接用户媒体、真实转写、运行时授权、市场服务或场景呈现。

## 为什么不直接复用旧 Provider

`server/src/providers.js` 的 CompatibleProvider 是保留实验：有 HTTPS 固定配置、禁止重定向及超时，但全量 `response.json()` 无响应字节上限，缺调用者取消/并发限额/持久费用预留；返回自由文本而非可信执行结果。旧会话历史不等同可验证来源闭包。

`runtime/src/creature-response.js` 当前包装标签明确是 `deterministic-local`、`llmUsed:false`。新供应商输出必须另有正确的来源标签，不能注入此接口后继续假报为确定性本地回应。实际执行授权和回执仍只能由宿主与内核产生。

## 真实供应商启用前缺少的具体条件

1. **接收者与协议**：用户认可的供应商/实际 API 端点、模型与版本。ChatGPT/Claude 产品名不等于已有 API 凭据或兼容 Chat Completions；各协议需单独验证，不自动切供应商。
2. **数据披露**：明确可发送的转写、主体个性和任务资料范围、接收组织及用途。不能把购买订阅或开麦权限当作允许传给所有模型厂商。
3. **安全凭据**：服务端受控配置；不索取聊天中的明文密钥，不入仓库/前端/日志。现有登录与本地协议探针不提供该凭据。
4. **费用边界**：明确总支出额度及允许的调用范围；发送前持久预留，未知响应不自动退款或重试。max_tokens 是请求参数，不是供应商扣费保证；没有 usage 只能标未知，不能写零成本。
5. **质量门槛**：固定合成反例，包括否定、引述、缺参数、错提供者、真实地点、条件语句及提示注入。严格 JSON 只是语法，不证明用户意图或值有来源；候选需独立确认，模型不得生成“业务已完成”事实。
6. **隐私与上下文**：首轮无媒体/历史/任意工具，限定必要资料。远程模型不可见隐藏状态不属于已证明的受控上下文；新请求不等于遗忘，不能宣称内核来源闭包覆盖供应商内部。
7. **取消与恢复**：停止本地等待/HTTP 不证明远端停止计算或计费；超时、关闭、撤权、场景变化后结果必须丢弃且保持未知事实，不自动重派。真实外部写操作仍不在当前模拟服务授权内。

当前没有核验或消耗真实供应商账户、余额或密钥；以上是进入下一阶段的条件，而不是断言用户没有账户。不因缺少这些条件要求用户现在停下提供凭据，先完成本机协议和交互验证。

## 交互推进不等于模型推进

自愿“录完即发送”只减少每轮一次按钮，不变成常开麦克风、自动确认服务或通用理解。默认关闭、每轮手动开始/结束、离页/后台停止，错误未知不自动重发。自动 VAD、真实连续对话、真机回声消除和扬声质量尚未验证，不能用组件测试替代这些证据。

## 本轮验证范围

- 含独立协议探针的 Node 聚合：191通过、6项真实依赖测试默认跳过；协议探针自身真实 loopback HTTP 7/7。
- Flutter完整组件集141通过、1项默认跳过，静态分析和Web release构建通过。
- 本轮未改ASR/服务后端主链，未重新启动任何本地大模型，也没有外部供应商推理。新增模式使用假录音器/播放器做状态机测试，不是假装真人采集。
- 未知路线后台恢复缺口由内部只读审查指出并修复；只保留绑定提案元数据，新的录音/确认仍锁住。先前测试中不合法的生命周期跳转已改为Flutter规定的完整转换序列，最终全套重新通过，不以失败旧日志作成功证据。
