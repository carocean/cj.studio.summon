# ADR 0004：唯一字节出口、上下文与恢复

状态：限定原型采用。只模拟效果，不启用真实业务写操作。

## 决定

一个进程内broker持有唯一出站能力；Agent/生成器只提交数据提案，拿不到socket、数据库路径、任意文件句柄或可执行回调。首版执行器是编译进可信宿主的封闭确定性配置（如读取已绑定文本并生成受限输出），不接受插件代码。不能把普通Node进程解释成已经实现安全沙箱。

broker只读取已持久化的不可变快照，重新验证C1摘要、contextDigest、委托/来源闭包、接收方及当前世代。ExecutionContext由broker从真实输入句柄构造，不由Agent自报；输入和上下文在prepare冻结，运行中新增来源成为下一活动的新显式输入。没有共享未登记模型线程、工具缓存或worker记忆。

### 缓冲出口

首版输出完全缓冲，最多64KiB规范字节；过大直接失败，无分片/流式输出。披露门紧邻出口消费，不能先把字节交给UI再核验。已交出的字节无法撤回，不声称即时远程遗忘。回执交付与业务效果状态独立。

同活动只一个active slot。consume事务返回给broker一次内部状态变更，不把可发送函数/令牌作为普通命令返回值；command重放只得到历史ack。broker同步检查slot/fence并消费出站记录的本进程发送资格，唯一调用受控模拟接收端。不得因为“重放返回成功”再调用发送。

### 模拟外部接收端

模拟sink接收不可变完整缓冲，不执行真实订单、付款、设备或消息动作；它独立持久存储(authorityDomain,effectId)+effectDigest并绑定原活动/控制者，查询也校验该归属，异域同值不能串结果。fence核验/更新、摘要检查、效果去重和写入在同一sink事务内；先检查fence及摘要，再返回旧结果或写新效果，旧fence不能绕过检查直接获得缓存成功。它可声明测试fence域并拒绝旧attempt。这个sink只证明协议可演练，不证明任何真实商户支持幂等/隔离。

消费后任一崩溃恢复uncertain。恢复不会自动推进旧outbox；仅允许经受控查询从sink核对事实，或由明确安全重试协议建立新attempt、旧slot退休、effectId保持。查询自己也是受限活动，不用恢复权限读取其他主体数据。预算unknown保持保留，不能在重启时归零。

## 撤权与隐藏状态

执行前、消费前、输出披露前检查各自世代；中途撤权禁止新披露与新动作，但已发生事实仍受保护入账。跨attempt长期状态必须是带来源标签的显式ContextResource；受限上下文不能在公开尝试里复用。

首版不接未知第三方模型历史。后续若用新隔离worker，必须实测旧缓存/内存/文件/会话不可达，并且新注入材料仍继承原标签。新请求ID/提示模型忘记不是隔离证据。准备后并发修改源资源只产生新版本，旧快照内容不变，但撤权世代仍影响旧快照能否使用。

## 验收边界

一个Permit多次消费/不同commandId不产生双发送；同活动第二prepare被拒；原对象和已返回副本修改不改变出站字节；恢复时不自动发送；sink查询证实事实但不触发效果；出站前撤权失败；消费后完成的迟到回执不被取消抹掉；私密context→撤权→公开输入无法洗成公开输出。

真正的进程隔离、流式感知/播放、远端认证、生产网络和真实写操作都是后续独立接入任务。本ADR不授权或证明它们。
