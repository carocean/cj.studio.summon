# ADR 0003：首版主体、执行器及回执身份

状态：限定原型采用。无公网认证、生产密钥或第三方账号联邦声明。

## 决定

首版无网络接入，仅受信任本地测试宿主创建Principal与不可伪造的进程内身份句柄。句柄通过私有WeakMap绑定authorityDomain、principalId与会话世代；业务传入的字符串owner/issuer/role不认证身份，伪造形状相同对象不能通过。重启旧句柄无效，宿主必须明确重新认证并取得新句柄；持久资源归属不随句柄变化。

管理宿主注册固定执行器配置与事实签发者，不向Agent开放注册API。配置至少绑定实现版本/摘要、允许操作、上下文模式、最大输入输出、成功验证器及其发证权限。首版只允许受控纯确定性运算和模拟接收端，不加载用户JS、第三方插件或未知模型持久上下文。

执行环境而非Agent构造ExecutionContext清单：只从经核验资源快照装配输入、历史和记忆；读取集合与完整来源闭包由环境记录并冻结。禁止Agent提交一张自称完整的来源表然后直接获得可信标签。模型/观察内容只能形成不可信候选，不能注册身份或授权。

## 回执

Receipt通过宿主所注册issuer句柄进入；核验issuer有权对该ServiceContract、效果ID和证据等级发证。普通执行器只有派发证据权，不默认有业务成功权。模拟服务的accepted与completion分别由预注册模拟接收者出具；可选观测确认由独立模拟观测源出具，不能让模型输出字符串冒充它。

同issuer+issuerMessageId去重，相同ID异摘要登记冲突并拒绝升级成功。成功验证器是宿主注册的有限函数/模式，不从生成服务文本eval。核对原意图、效果摘要、attempt、Permit及签发资格后才派生事实状态。

## 授权与审计分开

可信身份只证明谁，不证明能做什么；每个命令仍检查Grant、委托链、数据标签、作用域和世代。授权撤销后仍可凭既有受限事实登记权接纳匹配该效果的迟到回执，但不能因此披露结果或执行补偿。事实登记权不得用于读其他活动或提交任意业务载荷。

日志只写稳定错误码/最小必要关联ID，不写token、原文/媒体/完整模型上下文。测试凭据为合成身份，不从现有APP_TOKEN承接。

## 不保证及升级门槛

WeakMap句柄不是进程隔离，不能抵挡任意代码执行或恶意同进程插件。当前TCB包括宿主、内核、受控执行环境及固定验证器；所有未知代码均不在其中。以后跨进程/设备接入须另做身份签发、mTLS/签名、密钥轮换、重放与撤销协议ADR，不把本地句柄序列化给远端。

验收：伪造句柄失败、跨租户失败、旧会话世代失败、Agent自报issuer失败、合法低等级回执不能提升业务成功、来源闭包由环境生成、准备后对象改写不改变身份/输入快照。
