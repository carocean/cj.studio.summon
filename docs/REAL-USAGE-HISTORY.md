# 真实使用驱动的常用栏（设计，尚未实现）

用户允许默认替身下方小排，只展示实际常用生物及以前生成并经常使用的内容。空历史必须空；不回填默认注册生物、研究数据、旧fixture或生成次数。先完成跨需求保稿/恢复，再落地此切片。

## 计数边界

- 明确选择且真实成功切换生物可记一次；同值选择、自动情境切换、设主生物不计。
- 用户明确打开内容且对应route完成呈现可记一次；模型生成、预取、read/current/query、后台恢复均不计。同一回合编辑/保存不叠加，保存回执只关联持久副本。
- 最多证明受控客户端报告呈现，不证明人类注意力，不授予任何权限。测试必须隔离store，不能靠客户端isTest或模型标签鉴别真实用户行为。

新增owner域小索引仅存kind/targetId/useCount/lastUsedAt，不复制正文、ASR或授权。owner由宿主认证handle确定；时间/计数由宿主生成。稳定回合命令ID、对象与版本绑定，重试/查询不重复记账；容量耗尽停止学习而不阻断用户使用，不淘汰去重信息后容许旧请求再累计。

## 入口与恢复

常用项只携带引用，点击必须重新核验目标。生物点击不能恢复听视觉许可；切换时保留现有未提交草稿。已保存内容通过readSaved读取，不依赖原麦克风权限，不复活旧编辑会话。临时内容仅在实际session/context/版本/期限仍有效时可操作，关闭/过期/失效的不自动重建。跨需求恢复通道必须先验证，不把latest discovery pointer误称权限，也不让常用栏成为绕过宿主授权的捷径。

最初可按次数再按最近使用排序，仅少量条目；未连通的银行、地图等不填占位。当前SceneLab固定demo-owner且selectCreature没有命令回执，不能声称已有多租户或可靠使用历史。常用生物的计数应与明确选择的原子回执绑定；普通查询不改变历史。
