# 合成生成场景纵切：验证记录

本轮验证对象是可运行的本机闭环，不是通用生成式操作系统完成声明。

## 实际执行过的链路

- 真实Node loopback HTTP与SQLite：合成听视觉事件→生物情境切换→结构化三字段表单→保存修订→微内核Source/Grant/Context/Artifact/Permit→独立模拟sink→受保护回执。
- 收起视图与服务重启保留任务；明确切回工作情境后恢复。重复提交不重复效果或预算。
- Flutter Dart客户端实际通过HTTP访问临时Node runtime，不只MockClient；临时数据库和进程由测试清理。
- Node全套：113项，110通过、3项需opt-in真实引擎测试跳过。内核40项、runtime5项包含在此计数内。

## 本轮发现并修复

1. 中断提交超过授权有效期后永久卡在submitting：增加明确expired终态、未消费取消和新任务出口，旧任务归档，不自动续期。
2. 只带revision的旧任务请求可能操作同revision的新任务：所有任务操作绑定activityId，新建绑定previousActivityId；跨任务旧请求拒绝。
3. Flutter实验入口曾误放到设置弹框：移动到主感知页AppBar，增加首页可达/返回回归。

## 保证边界

合成听视觉按钮不是实际音视频采集；确定性业务模式不是真实LLM生成；生物的静态名称/性格不是已实现的伙伴智能；模拟回执不是实际开户。原ASR/OCR实验仍独立，真机硬件、浏览器视觉人工检查、真实金融动作本轮未做。隐藏视图不取消持久任务，但不代表已实现完整后台持续调度。

先用这个闭环校验产品契约，随后逐个接入真实感知与获准模型，不能把核内安全测试代替用户体验验收。

Flutter最终代码复核：静态分析无问题；完整客户端测试50通过、1项真实HTTP需opt-in跳过；再独立启用实际HTTP测试1/1通过；最新Web release编译成功。包含首页实验入口可达/返回、个人情境收起工作字段、任务ID冲突不自动重提、取消与新任务等回归。没有可供手机直接安装的APK/IPA或已发布公网预览，loopback实验服务不等于手机可连接。
